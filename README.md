## Analytical Bot 2023 
Analytical Bot was created since 2023 for highschool open house project (ศิลปะหัตถกรรมระดับชั้นมัธยมศึกษาตอนปลาย). The program includes chatbot program which use google scraping method and data analysis system which divided into 2 parts:
raw data analysis and big data analysis where users can selected rows, columns for analyze the data
